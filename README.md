# Procesamiento del Lenguaje Natural — Portfolio

This repository showcases four coursework practices developed for Natural Language Processing. Each practice is kept in its own folder with its original coursework documentation and assets.

Practice 2 is not included as a folder because it was an audio-editing exercise focused on learning about phonemes. All projects in this portfolio were completed together with my lab partner, Javier Martín Fuentes.

## Repository structure

| Folder | Summary | Documentation |
|---|---|---|
| `p1/` | Butler resource-negotiation agents using an LLM and Ollama. | [Practice 1 README](p1/README.md) |
| `p3/` | PLNCG26 file encoding, decoding, and detection utilities. | [Practice 3 README](p3/README.md) |
| `p4/` | TUI for classical, semantic, and RAG search over *Don Quijote de la Mancha*. | [Practice 4 README](p4/fdi_pln_2611_p4/README.md) |
| `p5/` | Causal language model and NER system built with BPE, attention, training experiments, and inference tools. | [Practice 5 README](p5/README.md) |

## Notes

- Practice 1 and practice 5 include independent Python project metadata and lockfiles.
- Practice 3 is a standalone script whose external dependency is `typer`.
- Practice 4 is presented as source code plus its intentional wheel distribution in `p4/dist/`.
- The repository retains coursework corpora, annotations, embeddings, model artifacts, reports, and binary practice inputs. Some practice-5 generated reports preserve absolute cluster paths as provenance; these paths do not define the local execution layout.

The individual practice READMEs retain the original coursework language and detailed instructions.
